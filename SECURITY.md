# Seguridad

Si encuentras una vulnerabilidad, repórtala en privado por el formulario de **Security → Report a vulnerability** de este repositorio en GitHub. No abras un issue público.

Respondemos en un máximo de 5 días hábiles. Dentro del alcance: aislamiento entre organizaciones (RLS), manejo de API keys y secretos, verificación de webhooks, y el servidor MCP.
